# 웹 푸시 실기기 확인 (#34 완료 기준)

관리자가 실제 휴대폰으로 한 번 확인하고 결과를 적는다. 자동 시험(`pnpm test`, `pnpm e2e`)이 다루지 못하는 부분 — 실제 푸시 서비스(FCM·Apple)로의 전달, 앱이 꺼진 상태에서 누르기, Access 만료 뒤 로그인 — 만 남긴다. 값(쿠키·토큰·엔드포인트)은 적지 않는다.

**사전 조건**

- Cloudflare Access가 켜져 있고(`docs/ops.md` §7) `https://chat.2prostream.com`으로 접속된다. 웹 푸시는 HTTPS에서만 된다(임시 접속 코드 단계에서도 HTTPS라 시험은 가능하지만, 3번 "Access 만료"는 Access를 켠 뒤에 한다).
- 서버는 운영 빌드로 돈다(`pnpm build`, LaunchDaemon). 개발 모드는 서비스 워커가 없어 알림이 안 된다.
- 시험할 계정에 예약 기능이 없으므로 알림은 설정 → 알림 → **"테스트 알림"** 으로 만든다(알림함에도 남고, 누르면 설정 화면이 열린다). 다른 주소로의 이동은 아래 4번처럼 알림함에서 확인한다.

## A. Android (Chrome)

1. [ ] Chrome에서 `https://chat.2prostream.com` → Access 로그인 → 앱 로그인.
2. [ ] 설정 → 알림: 이 기기 상태가 "꺼짐", 페이지를 열기만 했을 때 **권한 창이 뜨지 않는다**.
3. [ ] "이 기기에서 알림 켜기" → Chrome 권한 창 → 허용 → 상태 "켜짐", 기기 이름 "Android · Chrome".
4. [ ] "테스트 알림" → 몇 초 안에 알림 표시(제목 "테스트 알림", 본문 2줄 이내, Agent Lee 아이콘).
5. [ ] **앱이 꺼진 상태**: Chrome 탭을 모두 닫고(최근 앱에서도 지움) PC 등 다른 기기에서 같은 계정으로 "테스트 알림"을 누른다 → 휴대폰에 알림 → 누르면 Chrome이 열리고 **설정 화면**으로 바로 간다.
6. [ ] **Access 만료**: Zero Trust → Access → Applications → Agent Lee → 세션을 강제로 끝내거나(사용자 세션 취소) 세션 시간이 지난 뒤, 다른 기기에서 테스트 알림 → 휴대폰 알림을 누른다 → Access 로그인 화면 → 로그인 → (앱 세션도 끝났다면 앱 로그인) → **설정 화면**에 도착.
7. [ ] 홈 화면에 추가(Chrome 메뉴 → 홈 화면에 추가)한 앱에서도 4·5번이 된다.
8. [ ] 설정 → 알림 → "끄기" → 다른 기기에서 테스트 알림 → 휴대폰에 **오지 않는다**(🔔 알림함에는 쌓인다).
9. [ ] 다시 켠 뒤 앱에서 **로그아웃** → 다른 기기에서 테스트 알림 → 휴대폰에 오지 않는다.
10. [ ] Chrome 사이트 설정에서 알림을 "차단"으로 바꾼다 → 설정 → 알림이 "브라우저가 차단"과 안내를 보여준다.

## B. iPhone (iOS 16.4 이상, Safari → 홈 화면 앱)

1. [ ] Safari 탭에서 설정 → 알림: "지원 안 됨"과 "홈 화면에 추가" 안내가 보인다(켜기 버튼 없음).
2. [ ] 공유 버튼 → "홈 화면에 추가" → 홈 화면의 Agent Lee 앱을 연다 → Access·앱 로그인.
3. [ ] 설정 → 알림 → "이 기기에서 알림 켜기" → iOS 권한 창 → 허용 → 상태 "켜짐", 기기 이름 "iPhone · 홈 화면 앱".
4. [ ] "테스트 알림" → 잠금 화면·알림 센터에 표시(본문 2줄 이내).
5. [ ] **앱이 꺼진 상태**: 앱 전환기에서 Agent Lee를 위로 밀어 종료 → 다른 기기에서 테스트 알림 → 누르면 앱이 열리고 **설정 화면**으로 간다.
6. [ ] **Access 만료**: A-6과 같이 Access 세션을 끝낸 뒤 알림을 누른다 → Access 로그인(홈 화면 앱 안에서 열림) → 로그인 → **설정 화면**에 도착.
7. [ ] 설정 앱 → 알림 → Agent Lee 알림 끔 → 앱의 설정 → 알림이 "브라우저가 차단" 상태를 보여주고, 다른 기기에서 보낸 테스트 알림은 🔔 알림함에만 쌓인다.
8. [ ] 앱에서 로그아웃 → 다른 기기에서 테스트 알림 → 오지 않는다.

## C. 방해 금지 (어느 기기든 1회)

1. [ ] 설정 → 알림 → 방해 금지 "사용", 지금부터 5분 뒤까지로 저장(예: 지금 14:02 → 14:00 ~ 14:07).
2. [ ] 다른 기기에서 그 계정으로 알림 2개를 만든다(테스트 알림 2번 — 테스트 알림은 방해 금지와 상관없이 바로 가므로, 예약 기능(#33) 이후에는 예약 결과로 시험한다). 현재는 서버 시험(`apps/server/test/notifications.test.ts`)으로 확인한 것으로 갈음하고, #33 머지 후 이 항목을 다시 한다.
3. [ ] 끝 시각 뒤 1분 안에 "알림 2개가 와 있어요" 푸시 1개 → 누르면 🔔 알림함.

## 판정

A·B의 2–6번이 모두 ✅이면 #34 완료 기준 "실기기: 수신, 앱 종료 상태 클릭 → 해당 위치, Access 만료 상태 클릭 → 로그인 후 해당 위치"를 충족한다. 결과를 이 파일 위 기록 양식과 #34에 남긴다.
