# 목업 리뷰 01 반영 결과 — 목업 v2 (PRD v0.5 기준)

대상: `mockup/index.html` (v2) · 리뷰: `mockup/REVIEW_01.md` · 이슈 #4

## 확인 방법

- 상단 검은 막대(리뷰용)에 화면별 링크가 있고, 오른쪽에 **“화면 사용자: 아들/엄마/아빠”**가 표시됩니다. 사이드바·알림함·런타임 칩·공유 모달은 그 사용자 기준으로 그려집니다.
  - 아들: 대화·인용, 새 대화, 코드·수식, 파일 뷰어, 공유받은 대화, 아티팩트, 설정, 런타임 없음, 오류·예외
  - 엄마: 금융, 예약, 예약 결과, 알림(휴대폰) · 아빠: 관리자
- 검은 **“목업 상태”** 막대(관리자 → 사용자·Access, 설정 → 알림)는 리뷰용 상태 전환이며 실제 앱 UI가 아닙니다.
- 바로가기 주소(리뷰·스크린샷용). 예:
  - `#chat?modal=shareModal&arg=conv-hist&sm=all&scope=m3` — 대화 “이 메시지까지” 공유
  - `#artifacts?modal=shareModal&arg=art-quiz` — 특정 가족에게 공유 중인 아티팩트
  - `#settings?tab=s-conn&modal=connModal&arg=member` — 아들의 연결 추가(Claude는 API 키만)
  - `#admin?tab=ad-rt&modal=connModal&arg=shared|self|forwife` — 공용 / 관리자 본인 / 엄마 대신 등록
  - `#admin?mst=manual|auto|drift`, `#admin?modal=userModal&arg=add`, `#admin?modal=previewModal`, `#admin?modal=pwModal&arg=add`, `#admin?modal=adminEmailModal`
  - `#admin?tab=ad-usage&sp=u-conn`, `#finance?art=1&sp=c-candle`, `#viewer?f=hwp&loc=t3r2`, `#sched-result?m=fail`
  - `#schedules?modal=schedModal&sp=cron|once|weekly`, `#settings?tab=s-noti&mst=denied|unsupported`, `?theme=light|dark`
- 헤드리스 Chrome 1440×900로 모든 화면과 주요 모달을 찍어 레이아웃을 확인했습니다(라이트·다크). 모바일은 `#mobile` 화면의 300px iframe 4개(대화, 칩 하단 시트, 예약+서랍, 아티팩트 전체 화면)로 확인했습니다.

- 관리자 런타임 탭의 Codex 실행 방식을 “Codex SDK (폴백 CLI)” → **`codex app-server`**로(§4 기술 스택). Codex 모델 예시를 스파이크 결과의 `gpt-6.1-sol`, `gpt-6-astra`로.

## 판단이 필요했던 부분 · PRD 메모 (PRD는 수정하지 않음)

1. **아티팩트 공유의 버전 범위**: FR-14.4는 아티팩트 공유 시 어떤 버전이 보이는지 정하지 않았습니다. 대화 공유가 “살아 있는 공유”(FR-14.3)인 것에 맞춰 “공유 중에는 최신 버전이 보임”으로 그렸습니다. 버전 기록까지 보여줄지는 SCREEN.md에서 확정이 필요합니다.
2. **사용자 추가 후 예시 상태**: 관리자 화면은 상태 A/B/C를 리뷰용 막대로 바꿔 보여줍니다. B에서 엄마를 추가해 임시 비밀번호까지 보는 흐름이고, 저장 뒤 표 자체가 3명으로 바뀌는 애니메이션은 넣지 않았습니다(C가 3명 상태).
3. **터치 기기의 인용 동작**: PRD FR-5.3은 “마우스를 올리면 미리보기, 누르면 열기”만 정합니다. 터치는 “첫 탭 미리보기 → 미리보기 안에서 열기 / 두 번째 탭 열기”로 정했습니다.
4. **암호 HWP 감지 시점**: 암호 여부는 파일을 읽어야 알 수 있어 “올린 직후 서버가 확인해 같은 자리에 표시”로 그렸습니다. FR-4.6의 “업로드 전 알림”은 용량·개수에만 적용했습니다.
5. **예약 겹침 예시**: FR-8.7의 “앞 실행이 끝나지 않았는데 다음 회차” 예시로 ‘바로 실행’ 직후 정규 회차를 건너뛰는 경우를 넣었습니다. 수동 실행도 겹침 판단에 포함하는지는 PRD에 명시돼 있지 않습니다.
6. 수식은 외부 라이브러리 금지 조건 때문에 CSS로 렌더 결과만 흉내 냈습니다. 실제 구현은 FR-3.2대로 KaTeX를 씁니다.
