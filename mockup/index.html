단진자의 주기는 진폭이 작을 때 T = 2π√L/g 로 근사해요. 양변을 제곱해 정리하면 중력가속도를 구하는 식이 나와요. FR-3.2 수식(KaTeX)

g = 4π²LT²  ≈  9.8 m/s²

그래서 T²을 세로축, L을 가로축으로 그리면 직선이 되고, 기울기로 g를 구할 수 있어요.

python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("단진자_측정.csv")   # 열: L(m), T(s)
df["T2"] = df["T"] ** 2
slope = (df["T2"] / df["L"]).mean()
g = 4 * 3.1416**2 / slope

plt.plot(df["L"], df["T2"], "o-")
plt.xlabel("L (m)"); plt.ylabel("T² (s²)")
plt.title(f"g ≈ {g:.2f} m/s²")
plt.show()

코드를 그대로 내기보다, 그래프에서 점들이 직선에서 벗어나는 이유(측정 오차, 큰 진폭)를 보고서 ‘오차 분석’에 직접 써 보면 좋아요. NFR 청소년·학습 지원
